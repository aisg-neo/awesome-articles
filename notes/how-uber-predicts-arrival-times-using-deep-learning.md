Uber's growing XGBoost ETA model became difficult to scale while meeting millisecond latency requirements. DeepETA uses a neural network to predict the difference between a routing engine's travel-time estimate and observed outcomes, using historical and real-time signals. The model provides a shared ETA refinement system across mobility and delivery.
