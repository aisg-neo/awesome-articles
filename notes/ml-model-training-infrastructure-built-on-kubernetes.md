Lyft built LyftLearn to provide a common platform for model development, training, retraining, and batch predictions across teams using different ML libraries. Kubernetes-backed environments and containerized model code support fast setup, reproducible runs, distributed training, and hyperparameter tuning. APIs, a CLI, and a dashboard expose the platform while tracking training history, performance, and cost.
