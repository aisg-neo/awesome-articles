Facebook explains how its News Feed ranking system personalizes content for more than two billion people using multiple machine-learning predictions. Models estimate actions such as likes, comments, and shares, and the system combines these predictions with objectives informed by user feedback. Multiple ranking stages make it possible to evaluate large candidate sets within the time available to assemble a feed.
