Uber's independently managed marketing pushes could overlap and required substantial manual coordination. Its Consumer Communication Gateway buffers notifications per user and uses ML scores with an integer linear program to choose delivery times. The optimizer incorporates constraints such as expiration, send windows, frequency caps, and minimum spacing between notifications.
