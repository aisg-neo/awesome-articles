year: 2024

Coinbase audited mobile and web request patterns to reduce unnecessary load during traffic surges. It addressed GraphQL resolver fan-out, N+1 requests, excessive polling, and unused data fetching, then added guardrails to prevent regressions. Fixing N+1 patterns reduced request counts by almost 90% in some cases.
