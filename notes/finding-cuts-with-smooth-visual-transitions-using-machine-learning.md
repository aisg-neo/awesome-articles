Netflix built a machine learning tool to help editors find match cuts between shots with similar visual composition or movement. The team assembled annotated shot pairs, extracted representations from media encoders, and trained classifiers to suggest compatible transitions. The tool was used to help edit a Firefly Lane teaser.
