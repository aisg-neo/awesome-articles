DoorDash built Iguazu to replace fragmented event pipelines with a common real-time processing platform based on Kafka and Flink. The platform transports events to analytics, machine learning, and monitoring destinations with schema management, observability, and independently scalable pipelines. Self-service automation reduced event onboarding from days to minutes.
