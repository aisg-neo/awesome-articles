Snap’s ML teams spent weeks collecting new feature logs and maintained overlapping feature infrastructure. It built Robusta, a declarative framework for shared aggregation features with near-real-time updates and offline generation. Associative and commutative aggregation blocks let the platform reconstruct point-in-time feature values for training without storing every minute’s complete feature state.
