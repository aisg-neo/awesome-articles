title: "Resolving code review comments with ML"
link: https://research.google/blog/resolving-code-review-comments-with-ml/
topics:
  - AI/ML
year: 2023
---

Google trained a model to propose code edits that address natural-language review comments, using developer activity for pretraining and reviewed changes for fine-tuning. Suggested edits are integrated into the review workflow and filtered to balance usefulness against incorrect suggestions. The deployed feature lets authors resolve a substantial number of comments with ML-generated edits, with annual time savings projected in the hundreds of thousands of hours.
