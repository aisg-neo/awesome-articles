Facebook developed Superpack to counter mobile app growth beyond what conventional compression could offset. It combines compiler analysis with compression, using program structure to improve repetition detection and entropy coding. Across its Android apps, it achieved average size savings of more than 20% compared with Android's default Zip compression.
