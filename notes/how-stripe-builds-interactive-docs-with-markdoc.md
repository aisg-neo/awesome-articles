Stripe's documentation mixed code and content in Ruby templates, making interactive and personalized pages difficult to maintain. It developed Markdoc, a declarative Markdown extension with custom tags, variables, conditionals, and React rendering. Its syntax tree also supports static analysis and automated content refactoring.
