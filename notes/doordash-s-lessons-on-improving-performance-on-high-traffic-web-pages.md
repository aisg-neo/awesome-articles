DoorDash investigated slow high-traffic pages by examining JavaScript bundles, DOM size, API dependencies, render-blocking resources, and caching. Updating a dependency to enable tree shaking removed 300 KB from the compressed main bundle and showed an approximately 0.50% directionally positive conversion impact. Deferring below-the-fold rendering improved first input delay by 67% on mobile and 46% on desktop in a twenty-day experiment.
