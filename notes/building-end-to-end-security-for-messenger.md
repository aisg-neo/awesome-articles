Meta rebuilt Messenger protocols to make end-to-end encryption the default for personal conversations while preserving messaging features and safety tools. The work combines an encrypted messaging protocol with Labyrinth, which protects stored message history across a user's devices. The article explains the cryptographic and application changes behind the start of this rollout.
