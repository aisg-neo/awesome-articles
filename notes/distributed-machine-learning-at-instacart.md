Instacart built distributed ML infrastructure using Ray to support diverse CPU and GPU workloads while improving resource utilization. The platform replaced less flexible execution patterns and supports training thousands of production models. In one fulfillment workload, host CPU utilization rose from roughly 10–15% to as much as 80%, and end-to-end execution fell from about four hours to twenty minutes.
