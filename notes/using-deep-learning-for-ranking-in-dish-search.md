Swiggy built a deep learning ranker for dish search that combines semantic relevance with restaurant, popularity, distance, and delivery-time features. It learns from historical clicks using a pairwise margin objective that ranks clicked dishes above shown and random dishes. Adding restaurant features gave the largest improvement in mean reciprocal rank over the semantic baseline.
