LinkedIn built shared infrastructure for embedding-based retrieval to improve semantic matching in recommendations and job search. The platform manages embedding generation, retrieval, and version alignment so application teams can combine member, query, and contextual information. This extends job matching beyond the text-based retrieval used previously.
