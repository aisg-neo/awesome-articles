Dropbox added document summaries and question answering to web file previews by extracting text, generating embeddings, and selecting relevant content for LLM requests. The team refined chunk selection, prompts, and embedding caching to control latency and avoid sending irrelevant context. Cost per summary fell by 93% and cost per query by 64%.
