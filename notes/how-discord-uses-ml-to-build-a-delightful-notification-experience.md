Discord explores how to design a notification system that uses machine learning to decide whether, when, and through which channel to notify users. The design separates notification transport from ML decisions and introduces smart inputs and channels that can optimize content selection, timing, and batching independently. This decomposition addresses the complexity of repeatedly reconsidering notifications across large user and message populations.
