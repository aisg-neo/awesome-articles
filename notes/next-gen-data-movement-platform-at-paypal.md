PayPal's many one-off data movement tools became expensive to maintain and difficult to extend across its storage systems. It built a platform using Apache Gobblin for data transfer, Airflow for scheduling, and centralized metadata and onboarding APIs. The article describes clear component boundaries, security across zones, and support for configuration changes and rolling deployments.
