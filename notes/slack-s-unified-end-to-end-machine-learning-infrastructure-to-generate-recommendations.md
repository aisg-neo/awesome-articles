Slack built Recommend API to avoid creating separate infrastructure for every product recommendation feature. The framework shares data processing, training, candidate generation, feature access, serving, logging, and monitoring across recommenders. It supports uses such as conversation suggestions, channel recommendations, and invitation timing, while making new experiments easier to launch.
