Twitch trained a model to help safety specialists review the growing volume of custom emotes. It combines image and character-based emote-code embeddings, using prior human reviews as labels and MobileNetV2 transfer learning for image features. The model automatically approves a large portion of static emotes so creators can use them sooner and specialists have fewer submissions to review.
